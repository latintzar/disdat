# Export scope

This source beta contains the point-and-talk extension, agent setup/capture skills, token MCP and active website/library source. Peter’s original repository and the earlier private candidate retain the complete history.

## Retained website

The visible main page preserves its existing HTML, CSS and product demonstrations. Its poster, decomp and heatmap loop uses an authored CSS gradient. The unused compiled-orb loader/reveal/empty host were removed. The Library retains fifteen original token, spring, animation and UI specimens with local CSS/JSON export.

## Omitted historical experiments

The compiled ElevenLabs orb engine was acquired from its live site. Redistribution licence evidence for that specific engine/texture was absent, so the first source export excludes that experiment, its research/lab route and its dependent Library orb/texture rows. The old unused React reference demos and their unverified stock/Apple images are also preserved privately. This export introduces no substitute visuals.

## Remaining Dis Dat source

## Website toolchain

The website uses Vite 7.3.7 and React plugin 5.2.0 with Node 20.19+ or 22.12+. This supported Vite branch and compatible plugin replace the older development-tool versions after npm audit reported advisories. The resulting locked dependencies report zero npm audit findings on 28 October 2026. The [official Vite release policy](https://vite.dev/releases) records supported branches.

## Validation boundaries

The extension preserves its capture/privacy boundaries and adds explicit microphone readiness/cancellation. Its real Chromium proof uses a fake microphone and mocked providers, including a recorder-chunk barrier; physical microphone/clipboard permissions and selected-account authentication remain real-world acceptance checks.
