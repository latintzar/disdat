# Dis Dat website

The active Dis Dat design and product demonstrations are preserved. The main page and `/download` introduce the Chrome extension and agent setup with the user's own provider keys. The Library retains fifteen token, spring and UI specimens with local export.

```sh
npm ci
npm run build
npm run preview
```

Use Node 20.19+ or 22.12+ and run those commands in this directory. The main React page embeds `public/research-vision.html` with the existing demonstrations. Source and install links target `latintzar/disdat`. [Export scope](../docs/export-scope.md) records the historical compiled-orb experiment, unused reference demos/media and macOS installer preserved in the private original.

Hosted account, billing and policy routes retain their existing service dependency. The main installation flow links to local setup and configuration documentation. [Website hosting](DEPLOY.md) describes the static build and page routing.
