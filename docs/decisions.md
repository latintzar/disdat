# Extraction decisions

Retrospective, 28 October 2026. This records choices made for the initial source beta. [Provenance](../PROVENANCE.json) identifies the original files and commit.

| Choice | Reason and tradeoff | Source |
|---|---|---|
| Private runtime outside the checkout | CLI setup copies the extension to an owned runtime directory and writes local configuration with private permissions. A source checkout stays suitable for sharing. Changing keys or mode requires rerunning setup and reloading the unpacked extension. | [CLI](../tools/disdat.py): `paths`, `write_private`, `setup`, `doctor`; [configuration](configuration.md) |
| Explicit provider and account selection | Own-key mode selects direct Deepgram and Groq/Anthropic requests before consulting hosted identity. A saved hosted session therefore preserves the user's explicit local choice. Audio and briefing input still reach the selected external providers; credentials, account access and usage belong to that user. Hosted mode remains an explicit alternative. | [runtime](../extension/runtime.js); [background](../extension/background.js): `getToken`, `deepgramBytes`, `llm`; [models](model-support.md) |
| One initiating tab, window and top frame | Background session mutations and artifact work verify Chrome's sender identity against the initiating tab/window. Same-tab navigation resumes capture through session storage. Screenshots require that tab to be active before and after capture, and discard frames across tab changes. This bounds capture to one tab; moving or closing it ends recording. | [background](../extension/background.js): `owns`, `captureOwner`, `captureShot`, navigation/tab listeners |
| Explicit microphone readiness and cancellation | The existing pill shows microphone startup with a cancel action, then enables Stop and capture sensors after the recorder starts. Failure returns to microphone setup. Background rejects pending Stop and stale-session cancellation; offscreen session IDs/generations retire delayed streams while preserving a restarted recorder. Startup can take permission/device time, so its pending phase is separate from recorded audio. | [content](../extension/content.js): `showMicPending`, `audioStateChanged`; [background](../extension/background.js): `startAudio`, `stopSession`; [offscreen](../extension/offscreen.js): `start`, `stop`; [regressions](../tests/runtime.test.cjs) |

Browser download/clipboard failures remain recoverable local states. | [private downloads](../extension/private-downloads.js); [offscreen](../extension/offscreen.js); [background](../extension/background.js): `localCaptureDownload`; [content](../extension/content.js): `packageBundle`, `doCopy`; [manifest](../extension/manifest.json) |
| Separate source proof from live acceptance | The Chromium proof uses a fake microphone and mocked providers, then checks readiness/failure/cancellation, a real recorder chunk, navigation, privacy boundaries, download and unpack. CI includes this browser job, the nine offline Python and sixteen Node tests, and the website build. Physical-device permissions and selected-account authentication remain documented acceptance checks. | [browser proof](../tests/browser_extension.py); [offline tests](../tests); [CI](../.github/workflows/check.yml); [release scope](../RELEASE-STATUS.md) |

Historical copied-engine research/lab code, its dependent Library rows and unused reference demos/media stay in the private original while their redistribution provenance is unresolved. The Library retains fifteen token/spring/UI specimens and local export. The original architecture notes in [original](original) preserve the product's earlier implementation work and proposals. The choices above describe this extraction.

## 28 October 2026: portable website and installer

The approved Disdat.dev Home and Download React components now build through the repository's ordinary Vite entry point. Its fonts and product demonstration are local files, with font notices and source hashes retained. The owner's compiled account snapshot and deployment metadata stay outside this export; optional hosted client routes remain in source.

A clone configures its own API and public Supabase client settings. Hosted routes show setup before mounting their auth hooks when those settings are incomplete. Every retained account, billing, referral, MCP and Figma endpoint uses the configured API base. This keeps the original service contracts while making account ownership explicit. Private provider and billing values belong on the recipient's backend.

The installer packager uses a reviewed file/hash manifest rather than copying an arbitrary extension directory. It overrides any private local configuration with a pinned setup-only template. Fixed archive metadata reproduces the current published ZIP byte for byte. Extension updates therefore require reviewing that manifest and hash as well as the code. The 27 runtime source files are unchanged by this website update.

The retained Library uses the same local font families, including its original IBM Plex Mono weights from Google Fonts under IBM's OFL notice. Small-screen controls wrap within their existing specimens, and its closed chat rail stays outside the reading/focus surface. Chat retains its original `/x/labchat` contract with an explicit recipient API base; the default offers setup before a service request. Local token export remains independent of that optional service.

## 29 October 2026: local download defaults

The convenience extension ZIP selects the recovered Qwen/Whisper mode. Local setup keeps WebLLM 0.2.84's selected prebuilt record, verified against its npm gitHead, so first recording fetches the compatible upstream library and model weights. The optional --model-lib path replaces only that library inside a private runtime. This preserves the original on-device pipeline and avoids asking an installer to locate an internal binary manually. The public archive contains licensed loader/runtime code; separately hosted MLC binaries and model weights retain their upstream terms. Own-key cloud and hosted modes remain explicit setup choices. Hardware inference acceptance is recorded separately from mocked capture and offline tests.
